# axi-soc-versal-core

**Documentation:** https://slaclab.github.io/axi-soc-versal-core/

[DOE Code](https://www.osti.gov/doecode/biblio/165458)

AXI-Lite, AXI-Stream, DMA, and AI Engine platform library for SLAC Versal
SoC designs, including the shared Yocto build, used as a `git submodule` by
downstream firmware projects.
